## Finding

**Source:** Qodo review on 0c2f227.

**Location:** `tsb_tui/screens/credentials.py` — `CredentialsScreen._failed`, ~lines 226–235.

**Description:** `_failed` checked `_live_table() is None` before it checked for a 401 status.
A list request that returned 401 after the screen's table was torn down (screen replaced while
the load was in flight) returned early at the table check and never called `notify_api_error`.
The app missed its session-expiry redirect (`_to_login`).

The generation guard was correct and remained first: an older load's answer (401 or otherwise) is
still dropped there. Only a *current-generation* 401 that arrived after the table disappeared was
silently swallowed.

## Test

**File:** `tests/test_credentials_screen.py`  
**Name:** `test_a_current_generation_401_after_the_table_is_gone_still_routes_to_login`

**What it does:**
1. Opens the credentials screen and waits for the table to mount.
2. Captures `screen._generation` (the current load's generation).
3. Removes the `#credentials-table` widget and yields a tick (`await pilot.pause()`) so Textual
   processes the removal; asserts `_live_table()` is None as a pre-condition.
4. Calls `screen._failed(generation, ApiError(401, "unauthenticated", "login gone"))` directly —
   same generation, so the generation guard passes; table is gone, so only the fixed order prevents
   the early return.
5. Waits up to 10 s for `app.workspace() is None` (notify_api_error → _to_login popped the
   workspace).

The pre-condition (`_live_table() is None`) passed. The workspace never disappeared because

## Fix

**File:** `tsb_tui/screens/credentials.py`

**Change:** Moved the 401 branch above the `_live_table()` guard in `_failed`. The generation
guard remains first (unchanged). The reordered body:

```
_failed(generation, exc):
    if generation != self._generation:   # stale — drop
        return
    if isinstance(exc, ApiError) and exc.status == 401:
        self.app.notify_api_error(exc)   # redirect regardless of table state
        return
    if self._live_table() is None:       # non-401 failure, table gone — drop
        return
    if self.is_attached:
        self.query_one("#cred-status", Static).update(failure_message(exc))
        self.loaded = True
```

Every other failure and every success still drops when the table is gone.
