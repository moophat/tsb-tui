## Concerns

**Pre-existing skips in `test_launcher.py`** (not introduced by this change):  
The packaging test run shows 2 skips from `test_launcher.py` lines 71 and 88:
`run inside the CI image, which pins the mingw-w64 cross-compiler`. These were present before
this fix (42 passed, **2 skipped** in the before run). The packaging job's no-skip rule
(`grep -E '^SKIPPED|[0-9]+ (skipped|...)'`) would catch them in CI if the actual docker run
produces the same SKIPPED lines — that is a pre-existing concern outside this PR's scope.

---

## What was not verified

- The fix was not run inside the `ci-tui-py` Docker image (not available locally); the
  command was run directly with the system Python 3.12.3 against the same source tree.
- `test_staged_macos_zips`: confirmed it hard-fails (assert) rather than skips when
  `packaging/out/` is empty, by reading the source; not exercised with an empty `out/`
  because that would require temporarily renaming the directory. The source is unambiguous.
- The release job (which runs the deselected tests with real cached inputs) was not exercised.
